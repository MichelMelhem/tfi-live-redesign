# TFI Live redesign: Hick's Law prototype

Interactive prototype for CSC1058 (DCU) group project, GroupProject AC.
"Fewer Choices, Faster Departures: Applying Hick's Law to TFI Live to Support DCU Students Catching Their Next Bus Between Classes."

**Open the prototype:** https://michelmelhem.github.io/tfi-live-redesign/

Best on a phone. On a desktop it shows inside a phone frame.

- Departure times are scripted demo data, not live TFI data, so every test session sees the same thing.
- Facilitator panel: press and hold the clock on the Now screen for 1 second (or press F). It times tasks, counts taps and exports CSV.
- Direct screen links: `#now` `#detail` `#map` `#mapall` `#plan` `#search` `#more` `#results` `#onboard`

Screenshots are in `/screenshots`.
